# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나
- 사용자는 본인이다.
- 친구들에게 좋아하는 영화를 추천할 때 사용한다.

## 2. 무엇을 하려고
- 내가 본 영화를 정리해서 데이터화한다.
- 친구들에게 영화를 추천하기 위한 용도로 사용한다.
- 영화들을 S/A/B/C/D 티어로 나누어 정리한다.

## 3. 화면과 동작
- 영화 티어는 `S`, `A`, `B`, `C`, `D`로 구성한다.
- 정해진 영화 목록을 화면에 보여준다.
- 사용자는 새로운 영화를 추가할 수 있어야 한다.
- 사용자는 영화를 원하는 티어에 배치할 수 있어야 한다.
- 창을 껐다 켜도 추가한 영화와 티어 배치가 유지되어야 한다.

### 아직 정하지 않은 것
- 영화 정보를 어떤 형태로 보여줄지 정하지 않았다.  
  예: 제목만, 제목+포스터, 제목+감독, 제목+개봉년도, 한줄평 등
- 추가한 영화를 수정하거나 삭제할 수 있는지 정하지 않았다.
- 친구들에게 공유하는 방식이 정해지지 않았다.  
  예: 링크 공유, 이미지 저장, 화면 캡처 등

## 4. 필요한 자료
- 기본 영화 목록은 다음과 같다.
  - 기생충
  - 인터스텔라
  - 라라랜드
  - 센과 치히로의 행방불명
  - 어벤져스: 엔드게임
  - 범죄도시
  - 타이타닉
  - 토이 스토리

- 영화 추가 기능에 필요한 입력 항목이 필요하다.
  - 현재는 영화 제목을 입력하는 방식으로 한다.

### 아직 정하지 않은 것
- 영화마다 저장할 정보가 정해지지 않았다.  
  예: 제목, 포스터 이미지, 감독, 개봉년도, 장르, 감상평, 추천 이유 등

## 5. 데이터 저장 방식
- 브라우저의 `localStorage`를 사용한다.
- 사용자가 추가한 영화와 티어 배치 정보를 브라우저에 저장한다.
- 새로고침하거나 창을 껐다 켜도 이전 상태가 유지되도록 한다.
- 외부 서버나 데이터베이스는 사용하지 않는다.

## 6. 완성 기준
- S/A/B/C/D 티어가 화면에 표시된다.
- 정해진 영화 목록을 확인할 수 있다.
- 사용자가 영화를 추가할 수 있다.
- 내가 본 영화를 티어별로 정리할 수 있다.
- 저장 기능을 통해 브라우저를 다시 열어도 기존 티어 상태가 유지된다.
- 친구들에게 추천용으로 보여줄 수 있는 형태가 된다.

### 아직 정하지 않은 것
- 완성된 화면의 구체적인 디자인 기준이 정해지지 않았다.
- 공유 기능의 완성 기준이 정해지지 않았다.
- 모바일 화면 지원 여부가 정해지지 않았다.
